Trigonometry Art

Setup

Math can create art.

Trigometric Graphs are graphs that depend on sin and cosine values. The x and y values depend on the time t.

This program generates points by calculating x and y values for different t values. It then draws a circle centered at each point.

Circles are the easiest example. The x value is cos(t) and the y value is sin(t). The minimum and maximum sin and cosine values are -1 and 1. The program multiplies the x and y values by the canvas' width and height. Afterwards, it moves the x and y values over by half the canvas width and half the canvas height.
